# Astralys — launcher

Launcher du serveur Minecraft **Astralys** (Forge 1.20.1), basé sur [HeliosLauncher](https://github.com/dscalzi/HeliosLauncher) (licence MIT).

- **Jouer** : télécharge Forge et les mods, puis rejoint directement le serveur.
- `distribution/` : liste des mods (liens officiels Modrinth) et informations du serveur. Une modification ici relance automatiquement la génération de `distribution.json` (onglet *Actions*).
- L'installateur Windows se construit depuis l'onglet *Actions* → **Launcher Windows** → *Run workflow*, puis se télécharge dans *Releases*.
